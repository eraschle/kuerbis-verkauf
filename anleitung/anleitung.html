1. Weshalb es dieses Programm gibt

Die Einnahmen aus dem Kürbisverkauf wurden seit 1998 in einer Excel-Datei (Kürbissverkauf 1998-2025.xlsx) festgehalten: pro Jahr ein Blatt, jeden Tag ein Betrag, dazu Wochen- und Jahrestotale sowie ein Übersichtsblatt. Das funktioniert, ist aber aufwändig: Jedes Jahr muss ein neues Blatt angelegt, Formeln kopiert und die Übersicht nachgeführt werden – und ein Vergleich über viele Jahre ist mühsam.

Das Programm Kürbisverkauf ersetzt diese Excel-Datei:

  • Tägliche Einnahmen einfach eintippen – Totale, Wochentotale und Statistik rechnet das Programm selbst.
  • Pro Saison Diagramme mit den Tageseinnahmen und dem laufenden Total.
  • Jahre direkt vergleichen – gleiche Wochentage liegen übereinander, damit z. B. Wochenenden vergleichbar sind.
  • Alle bisherigen Daten aus der Excel-Datei lassen sich übernehmen; ein Export nach Excel ist jederzeit möglich.
  • Keine Installation, kein Internet nötig, automatisches Speichern.

2. Herunterladen und am richtigen Ort ablegen

  1. Über den Link oben die Datei Kuerbisverkauf.exe herunterladen.
  2. Die Datei aus dem Ordner Downloads an einen festen Ort verschieben, z. B. in einen neuen Ordner Dokumente\Kürbisverkauf.
    Wichtig: Die Daten werden beim ersten Start neben der .exe gespeichert (siehe Kapitel 7). Liegt die .exe im Download-Ordner, landen auch die Daten dort – und werden beim Aufräumen leicht gelöscht.
  3. Optional: Rechtsklick auf die Datei → Weitere Optionen anzeigen → Senden an → Desktop (Verknüpfung erstellen).

Eine Installation ist nicht nötig. Das Programm braucht Windows 10 oder 11.

3. Erster Start: die Windows-Meldung

Beim ersten Doppelklick auf Kuerbisverkauf.exe zeigt Windows eine blaue Meldung «Der Computer wurde durch Windows geschützt».

Weshalb erscheint diese Meldung?

Microsoft Defender SmartScreen warnt bei jedem Programm aus dem Internet, das Windows noch nicht kennt. Grosse Softwarefirmen kaufen dafür ein Zertifikat, mit dem ihre Programme «signiert» sind. Das Kürbisverkauf-Programm ist ein kleines, selbst geschriebenes Programm ohne solches Zertifikat – darum steht dort «Unbekannter Herausgeber». Die Meldung sagt also nicht, dass das Programm gefährlich ist, sondern nur, dass Windows es nicht kennt.

Die Meldung nur dann übergehen, wenn die Datei wirklich über den Link oben (github.com/eraschle/kuerbis-verkauf) heruntergeladen wurde und Kuerbisverkauf.exe heisst.

Schritt 1: «Weitere Informationen» anklicken

Auf den unterstrichenen Text Weitere Informationen klicken. Nicht ausführen würde den Start abbrechen.

Schritt 2: «Trotzdem ausführen» anklicken

Jetzt erscheinen der Name der App (Kuerbisverkauf.exe) und der Herausgeber. Mit Trotzdem ausführen startet das Programm.

Diese Meldung kommt nur beim ersten Start. Danach startet das Programm ohne Rückfrage. Wird später eine neuere Version heruntergeladen, erscheint die Meldung für diese neue Datei einmal wieder.

4. Alte Excel-Daten übernehmen

Beim allerersten Start ist das Programm leer. So kommen die bisherigen Zahlen hinein:

  1. Oben rechts auf Importieren… klicken.
  2. Die alte Excel-Datei Kürbissverkauf 1998-2025.xlsx auswählen.
  3. Die Zusammenfassung prüfen und Übernehmen klicken.

Danach sind alle Jahre im Programm und werden automatisch gespeichert. Die Excel-Datei selbst wird nicht verändert.

5. Eine Saison erfassen

  1. Im Reiter Erfassung auf Neue Saison klicken, das Jahr bestätigen und Speichern.
  2. In der untersten Zeile Neu den Betrag des Tages eintippen und Enter drücken.
  3. Das Datum ist mit dem Folgetag vorbelegt und kann bei Bedarf geändert werden (z. B. wenn ein Tag ausgelassen wurde).
  • Beträge mit Komma oder Punkt sind beide möglich (12,50 oder 12.50).
  • Einen bestehenden Betrag korrigieren: in der Tabelle anklicken, überschreiben, Enter. Mit Enter und den Pfeiltasten springt man zur nächsten Zeile.
  • Es gibt keinen Speichern-Knopf – jede Eingabe wird sofort gespeichert. Unten im Fenster steht, wo.
  • Rechts sieht man Total, Anzahl Verkaufstage, Mittel pro Tag, besten und schwächsten Tag sowie die Diagramme.
  • Über das Feld Saison oben links lassen sich frühere Jahre ansehen und bearbeiten.

7. Wo die Daten gespeichert werden (JSON und Excel)

Das Programm arbeitet mit einer einzigen Datendatei: kuerbis-daten.json. Darin stehen alle Jahre und Beträge. JSON ist ein einfaches Textformat, das das Programm schnell und zuverlässig lesen und schreiben kann.

DateiWozu
kuerbis-daten.jsonDie eigentlichen Daten. Wird bei jeder Eingabe automatisch gespeichert. Standardmässig im selben Ordner wie Kuerbisverkauf.exe.
kuerbis-daten.json.bakSicherheitskopie: der Stand vor der letzten Speicherung. Liegt daneben und wird automatisch nachgeführt.
Excel-Datei (.xlsx)Nur für Import und Export. Das Programm speichert nicht laufend in Excel, kann aber jederzeit eine Excel-Datei erzeugen (Exportieren → Als Excel), die jede Person ohne das Programm öffnen kann.
JSON-Export (.json)Exakte Kopie aller Daten – ideal als Backup oder zum Weitergeben an jemanden, der das Programm ebenfalls benutzt.
Faustregel: JSON ist das Arbeitsformat und Backup, Excel ist zum Anschauen und Weitergeben.

Der aktuell verwendete Speicherort steht immer unten links im Programmfenster (Daten: …). Die Wahl des Speicherorts selbst merkt sich das Programm unter %APPDATA%\Kuerbisverkauf\einstellungen.json.

Backup: Ab und zu Exportieren → Als JSON wählen und die Datei auf einem USB-Stick oder in der Cloud ablegen. Oder den Speicherort gleich in einen OneDrive-Ordner legen (nächstes Kapitel).

8. Speicherort ändern

Oben rechts auf Speicherort… klicken ①. Es öffnet sich der Dialog Speicherort der Daten mit dem aktuellen Pfad und zwei Möglichkeiten:

② Daten an einen neuen Ort verschieben…

Speichert die aktuellen Daten am gewählten Ort und arbeitet ab dann dort weiter – z. B. in einem OneDrive-Ordner, damit die Daten automatisch gesichert sind. Liegt am Ziel bereits eine Datendatei, fragt das Programm nach, ob sie überschrieben oder stattdessen geöffnet werden soll.

③ Vorhandene Datendatei öffnen…

Verwendet ab sofort eine bestehende .json-Datendatei, z. B. eine, die jemand in einem gemeinsamen Ordner teilt, oder die Datei nach einem Wechsel auf einen neuen Computer. Die bisher geöffnete Datei bleibt unverändert an ihrem Ort.

Mit Schliessen den Dialog verlassen. Der neue Speicherort gilt auch bei allen weiteren Starts.

Eine gemeinsame Datendatei (z. B. in OneDrive) nie gleichzeitig auf zwei Computern bearbeiten – sonst überschreibt die eine Speicherung die andere.

9. Daten mit anderen teilen

  1. Exportieren ▾ → Als Excel (.xlsx) für Personen ohne Programm, oder Als JSON (.json) für Personen mit Programm.
  2. Die Datei per E-Mail, USB-Stick oder Cloud weitergeben.
  3. Die andere Person wählt Importieren… und die erhaltene Datei. Neue Jahre und Tage werden ergänzt. Wo sich Werte unterscheiden, zeigt das Programm eine Liste: pro Eintrag Mein Wert oder Importiert wählen (oder Alle meine behalten / Alle importierten übernehmen), dann Übernehmen.

Kurz zusammengefasst

  1. .exe herunterladen und in einen festen Ordner legen.
  2. Beim ersten Start: Weitere Informationen → Trotzdem ausführen.
  3. Importieren… → alte Excel-Datei → Übernehmen.
  4. Jedes Jahr: Neue Saison → Beträge in der Zeile Neu eintippen und Enter drücken.
  5. Gespeichert wird automatisch in kuerbis-daten.json; ändern unter Speicherort….
